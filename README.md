# BudgetMate 💰

BudgetMate is a mobile application for personal expense tracking and budget management developed using **Kotlin** and **Jetpack Compose**.

The application helps users monitor expenses, analyze spending habits, manage monthly budgets, and customize the interface according to their preferences.

## Features

### Expense Management
- Add expenses
- Expense history
- Delete expenses
- Expense categories
- Automatic date saving

### Analytics
- Total expenses calculation
- Average expense calculation
- Largest expense tracking
- Category-based analytics
- Visual progress indicators

### Budget Management
- Monthly budget setup
- Budget progress tracking
- Percentage of budget used

### Personalization
- Language switching (UA / EN)
- Currency selection (UAH / USD / EUR)
- Dark / Light theme support

### Support System
- Technical support screen
- FAQ section
- Operator request handling
- Support history

### Admin Panel
- Administrator login
- Operator management
- Reports system
- Request monitoring

## Technologies Used

- **Kotlin**
- **Jetpack Compose**
- **Material 3**
- **Navigation Compose**
- **SharedPreferences**
- **JSON**
